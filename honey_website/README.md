# Honey Website

This repository contains source code to deploy the honey website on Heroku.

## Requirements

### Dependencies

- Python 3.13
- [uv](https://docs.astral.sh/uv/)

### Setup

This repository uses [uv](https://docs.astral.sh/uv/) to manage dependencies.
1. Create virtual environment
    ```bash
    uv init
    ```
2. Install dependencies
    ```bash
    uv sync
    ```
3. If setting up PostgreSQL database, follow [Database Tables](#database-tables)
4. Download `.mmdb` files from [MaxMind](https://dev.maxmind.com/geoip/geolite2-free-geolocation-data/#integrating-geolite-databases-and-web-services) into `util/` and update the placeholder within `util/requests.py`

### Environment Variables

`PORT`: specifies port number to run the web server on

`DATABASE_URL`: specifies the PostgreSQL database connection URL

### IP Addresses
- We use GeoLite2 to store ASNs and location information from IP addresses and obtain IP address.
- The honey site does not store IP addresses or ASN/location data when `anonymized`.

### Database Tables
Create the following tables with the described columns:

**requests**
- *req_id* of type integer (primary key)
- *website_version* of type varchar
- *endpoint* of type varchar
- *req_type* of type varchar
- *req_headers* of type text
- *req_body* of type text
- *req_ts* of type timestamp

**improper_requests**
- *req_id* of type integer (primary key)
- *website_version* of type varchar
- *endpoint* of type varchar
- *req_type* of type varchar
- *req_headers* of type text
- *req_body* of type text
- *req_ts* of type timestamp

**experiment_times**
- *exp_id* of type integer (primary key)
- *website_version* of type varchar
- *webpage* of type varchar
- *start_req* of type integer (foreign key referencing a requests' req_id)
- *end_req* of type integer (foreign key referencing a requests' req_id)

SQL queries to create the tables are provided:
```sql
CREATE TABLE requests (
    req_id INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    endpoint VARCHAR(30),
    website_version VARCHAR(11),
    req_type VARCHAR(30),
    req_headers TEXT,
    req_body TEXT,
    req_ts TIMESTAMP
);

CREATE TABLE improper_requests (
    req_id INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    endpoint VARCHAR(30),
    website_version VARCHAR(11),
    req_type VARCHAR(30),
    req_headers TEXT,
    req_body TEXT,
    req_ts TIMESTAMP
);

CREATE TABLE experiment_times (
    exp_id INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    website_version VARCHAR(11),
    webpage VARCHAR(21),
    start_req INTEGER REFERENCES requests(req_id),
    end_req INTEGER REFERENCES requests(req_id)
);
```

### Creating Multiple Website Versions
- Create a text file, `versions.txt` at the root directory of this repository where each line contains a random string of size 10.
- Deploying the honey site will automatically result in `<domain_name>/<version_name>/` being deployed.
