# FP-Agent

This repository hosts the three sub-repositories containing code for our honey website, data collection automation, and classifier featurization, training, and analysis. The structure is as follows:

- `honey_website` contains the source code for the honey website and web server
- `data_collection` contains the source code used to run each browsing agent and perform tasks
- `classifier_training` contains the source code used to train and evaluate the XGBoost multi-class classifiers

Our data is made publicly available at [https://osf.io/j6b5p/overview?view_only=ac4ad89fbde540269aaaa85a2249cad6](https://osf.io/j6b5p/overview?view_only=ac4ad89fbde540269aaaa85a2249cad6).
